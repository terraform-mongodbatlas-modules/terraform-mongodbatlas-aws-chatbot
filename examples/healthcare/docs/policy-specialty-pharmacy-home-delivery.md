# Springfield Specialty Rx — Home Delivery Policy

Record type: Pharmacy policy | FICTIONAL DEMO DATA

Springfield Specialty Rx is Springfield Mutual Health's required pharmacy for specialty-tier drugs such as injectable growth hormone.

- Deliveries are scheduled every 28 days. The pharmacy calls or texts 5–7 days before each delivery to confirm the address and ask about side effects and missed doses.
- Refrigerated drugs ship in an insulated cold-chain box with ice packs and a temperature indicator. Do not use the medication if the indicator has turned red; call the pharmacy for a free replacement.
- An adult (18+) signature is required. If nobody is home, the driver returns the package to the pharmacy and reschedules for the next business day.
- Each delivery includes a free sharps container and alcohol swabs. Return full sharps containers with the prepaid mailer.
- Pharmacist support 24/7: 1-555-RX-SPRNG.
